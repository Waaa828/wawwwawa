最容易失分的六件事

  • 後序求值：先 pop 出來的是右運算元。減法和除法最容易算反。
  • 前序求值：從右往左掃，先 pop 出來的是左運算元，剛好相反。
  • 中序轉後序：比較 ISP(堆疊內) ≥ ICP(新進)。相等也要先輸出，所以同優先權由左算到右。
  • 環狀佇列：空和滿的條件相同，所以要空一格，最多只能放 MAX-1 筆。
  • 鏈結佇列：刪掉最後一個節點後，rear 也要設成 NULL。
  • top / front 的定義：題目沒說就照課本。top 指向最上面那筆資料；front 指向第一筆資料的前一格。

建議的學習順序

堆疊 → 直線佇列 → 環狀佇列 → 中序轉後序 → 運算式求值 → 迷宮回溯 → 合法出入序列 → 小測驗。

內容整理自你上傳的 Chapter 5 簡報。ISP / ICP 的數字是課本常見設定，考試請以你們課本的表格為準，重點是大小關係。

迷宮與回溯 backtracking

      
0 可以走，1 是牆。每到一個位置，依「上、右、下、左」（0、1、2、3）測試。可以走的方向全部 push 進堆疊，再 pop 一個前進。走到死路就 pop 回上一個路口，改走堆疊裡留著的方向。
